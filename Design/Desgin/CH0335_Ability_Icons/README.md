# CH0335 ability icons

- `CH0335_Deep_Implantation.png`: inward-pointing implant lines converge on a sealed dark core.
- `CH0335_Potential_Excitation.png`: the halo opens outward around a bright core with radial energy arrows.

Both icons are 512x512 RGBA PNGs with transparent backgrounds and no embedded text. They reuse the character halo silhouette and palette so they can be used as UI icons or referenced by a later SCML animation.
